# Проверка на macOS

Проверка проведена 30 сентября 2026 года на Apple Silicon под macOS 26.5.2. Использованы системная zsh 5.9 и Starship 1.26.0; Homebrew доступен в `PATH`.

До установки в изолированной временной домашней директории выполнены следующие проверки:

- каждый файл `config/zsh/*.zsh` прошёл `zsh -n`;
- `config/zsh/rc.zsh` и подключаемые модули загружены в интерактивной zsh; интеграция Starship и функция `zplugin-update` доступны;
- `starship explain` разобрал полную и компактную TOML-конфигурации без ошибок и показал macOS-значок ``.

## Установка и запуск

Затем выполнен полный `./install.sh`. Homebrew подтвердил актуальность уже установленных Starship, fzf, fd, bat, eza, ripgrep и zoxide; дополнительно установлен Git 2.56.0. Antidote клонирован в `~/.antidote`, плагины собраны в статический bundle, конфигурационные файлы скопированы. Для исходного `starship.toml` создана резервная копия `~/.config/customize-zsh/backups/starship.toml.20260930T093150Z.64590`.

После установки проверено, что в `~/.zshrc` находится ровно один блок проекта, bundle и обе конфигурации Starship существуют, а резервная копия сохранена. Новая интерактивная zsh завершилась с кодом 0; доступны функция `zplugin-update`, alias `ls=eza` и привязка `Ctrl+F` к `customize-zsh-fzf-files`.

Проверка интерактивного запуска использовала временные XDG-каталоги, Starship cache и базу zoxide. После установки пользователь визуально проверил prompt в терминале.
