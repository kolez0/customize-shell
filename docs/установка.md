# Установка

Перед установкой убедитесь, что zsh уже установлен и является доступной оболочкой. Установщик не устанавливает zsh и не меняет оболочку входа пользователя.

Склонируйте репозиторий и запустите установщик из его корня:

```sh
git clone git@github.com:kolez0/customize-zsh.git
cd customize-zsh
./install.sh
```

Установщик определяет поддерживаемую ОС, проверяет zsh, устанавливает Git, Starship, fzf, fd, bat, eza, ripgrep и zoxide, клонирует Antidote из его официального репозитория, затем копирует конфигурацию. Пакетный менеджер может запросить системное подтверждение или пароль через sudo.

Конфигурация zsh размещается в `${XDG_CONFIG_HOME:-$HOME/.config}/customize-zsh/zsh/`, `starship.toml` — в `${XDG_CONFIG_HOME:-$HOME/.config}/starship.toml`. Путь к истории учитывает `$XDG_STATE_HOME`, кэши zsh — `$XDG_CACHE_HOME`.

Установщик не заменяет `~/.zshrc`: он добавляет туда один помеченный блок подключения. Другие строки, в том числе добавленные Яндекс CLI и другими программами, остаются на месте. При замене существующего управляемого файла создаётся резервная копия в `${XDG_CONFIG_HOME:-$HOME/.config}/customize-zsh/backups/`, а её путь выводится в сообщении.

После установки откройте новую интерактивную сессию zsh либо перезагрузите настройки:

```zsh
source ~/.zshrc
```

Список системных пакетов и официальных upstream-источников приведён в [матрице платформ](поддерживаемые-платформы.md). Если обнаруженная ОС, версия или пакетный менеджер не поддерживаются, установщик прекращает работу до изменения конфигурационных файлов.
