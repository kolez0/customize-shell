# Поддерживаемые платформы

Матрица для первой реализации (проверена 30 сентября 2026 года). Для Debian, Ubuntu и Fedora перечислены выпуски, находящиеся в периоде обновлений безопасности поставщика на дату проекта; для Arch Linux поддерживается актуальная rolling-release-система. Перед выпуском проекта матрица и этот документ обновляются по официальным страницам жизненного цикла ОС.

| ОС | Поддерживаемые выпуски | Пакетный менеджер |
| --- | --- | --- |
| macOS | 14, 15 и 26 | Homebrew |
| Debian | 12 и 13 | `apt` |
| Ubuntu | 24.04 и 26.04 | `apt` |
| Fedora | 43 и 44 | `dnf` |
| Arch Linux | актуальный rolling release | `pacman` |

## Установка CLI-утилит

Для Starship требуется версия 1.22.0 или новее. На Debian 12, Ubuntu 24.04 и Fedora установщик использует официальный скрипт Starship, если пакет дистрибутива отсутствует или старее этого минимума. Остальные утилиты устанавливаются из системных пакетов либо способом, указанным upstream для `eza` и `zoxide`.

| Утилита | macOS | Debian/Ubuntu | Fedora | Arch Linux |
| --- | --- | --- | --- | --- |
| Git | Homebrew `git` | `git` | `git` | `git` |
| Starship | Homebrew `starship` | пакет `starship`, если официальный пакет доступен для выпуска; иначе установщик `https://starship.rs/install.sh` | официальный установщик `https://starship.rs/install.sh` | `starship` |
| fzf | Homebrew `fzf` | `fzf` | `fzf` | `fzf` |
| fd | Homebrew `fd` | `fd-find` (команда `fdfind` либо `fd`) | `fd-find` (команда `fd` либо `fdfind`) | `fd` |
| bat | Homebrew `bat` | `bat` (команда `bat` либо `batcat`) | `bat` | `bat` |
| eza | Homebrew `eza` | подписанный APT-репозиторий, на который ссылается официальная инструкция eza | пакет Fedora `eza` | пакет Arch `eza` |
| ripgrep | Homebrew `ripgrep` (команда `rg`) | `ripgrep` (команда `rg`) | `ripgrep` (команда `rg`) | `ripgrep` (команда `rg`) |
| zoxide | Homebrew `zoxide` | официальный установщик upstream, поскольку upstream помечает пакеты Debian/Ubuntu устаревшими | `zoxide` | `zoxide` |

Установщик не подключает сторонние зеркала и Copr. Для официального shell-установщика он сначала скачивает скрипт во временный файл с домена upstream, проверяет успешность загрузки и только затем запускает через `sh`. Не выполняется полное обновление системы; `apt-get update` обновляет только индекс пакетов.
