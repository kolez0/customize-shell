# Приглашение Starship

## Шрифт и значки

Значки приглашения рассчитаны на **JetBrainsMono Nerd Font Mono**. Обычный JetBrains Mono не включает Nerd Font glyphs. Если терминал показывает пустые прямоугольники или вопросительные знаки вместо значков, выберите JetBrainsMono Nerd Font Mono в настройках терминала. Проект не меняет шрифт или настройки терминала автоматически.

Чтобы использовать текстовые обозначения вместо значков, замените значения `symbol` в `starship.toml` и `starship-compact.toml`:

| Модуль | Текстовый вариант |
| --- | --- |
| `directory` | `dir ` |
| `git_branch` | `git ` |
| `nodejs` | `node ` |
| `python` | `python ` |
| `golang` | `go ` |
| `php` | `php ` |
| `kubernetes` | `k8s ` |
| `os` | `macOS`, `Debian`, `Ubuntu`, `Fedora`, `Arch` соответственно |

В компактной конфигурации языковые модули отсутствуют, поэтому замените там только `directory`, `git_branch`, `kubernetes` и значения `[os.symbols]`. Для текстового индикатора режима «только чтение» замените `read_only = " 󰌾"` на `read_only = " [ro]"`; для `stashed` в `[git_status]` можно задать `stashed = "stash:${count} "`. Остальные статусные маркеры уже используют читаемые текстовые или стандартные Unicode-символы.

## Выбор полной и компактной конфигурации

При ширине терминала от 120 колонок используется `${XDG_CONFIG_HOME:-$HOME/.config}/starship.toml`, где отображаются версии Node.js, Python, Go и PHP. При меньшей ширине zsh выбирает `${XDG_CONFIG_HOME:-$HOME/.config}/customize-zsh/starship-compact.toml` без языковых версий. В обоих вариантах путь, Git и Kubernetes сохраняются.

Оба варианта используют две строки: путь слева и состояние проекта справа в верхней строке; иконка ОС, SSH-имя при подключении и `$` — во второй. Код ошибки и длительность предыдущей команды выравниваются справа.
